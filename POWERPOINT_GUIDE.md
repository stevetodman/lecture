## 🔶 Slide 5: PPHN (Persistent Pulmonary Hypertension)

### Layout (Same 3-Column Format)

#### Column 1: Diagram
```
┌─────────┐
│ UPPER   │ ← Pink fill
│  BODY   │
└────┬────┘
     │
   ┌─┴─┐
   │ ♥ │  Heart
   │PA↑│  (show high PA pressure)
   └─┬─┘
     │
┌────┴────┐
│ LOWER   │ ← Blue fill ⚠️
│  BODY   │
└─────────┘

PDA: R→L (orange arrow)
PA pressure > Ao pressure
```

#### Column 2: Key Features
```
• R-to-L shunt via PDA
• PA pressure > Aortic
• Poorly oxygenated lower body
• PRESSURE-RELATED
• Normal anatomy
```

#### Column 3: Clinical
```
Pre-ductal SpO₂: 90-100%
Post-ductal SpO₂: 70-85%

Difference: >10%

⚠️ Differential cyanosis

Management:
• iNO (inhaled nitric oxide)
• Optimize ventilation
• Treat underlying cause
```

### Visual Emphasis
- **Bold** the R→L arrow
- Use ⚠️ warning symbol
- Highlight the blue lower body
- Show thick PA vessel (high pressure)

## 💊 Slide 9: Management Algorithms

### Split into Two Columns

#### If PPHN Suspected:
```
1. Optimize ventilation
   • Avoid hypoxia
   • Avoid hypercarbia
   • Correct acidosis

2. Inhaled Nitric Oxide (iNO)
   • 20 ppm typically
   • Selective pulmonary vasodilator

3. Hemodynamic support
   • Maintain systemic BP
   • Consider inotropes

4. Treat underlying cause
   • Sepsis, MAS, CDH, etc.
```

#### If Critical Coarctation Suspected:
```
🚨 URGENT ACTIONS:

1. Start PGE₁ infusion
   • 0.01-0.1 mcg/kg/min
   • Keep ductus arteriosus open

2. Cardiology consult STAT

3. Monitor for complications
   • Metabolic acidosis
   • Renal dysfunction
   • Necrotizing enterocolitis

4. Prepare for surgical repair
```

### Design
- Use numbered lists
- Icons for each step
- Different background colors (yellow for PPHN, red for coarctation)
- Bold critical actions

- **Headings:** Calibri Bold, 40-44pt
- **Subheadings:** Calibri Bold, 28-32pt

### Spacing
- Generous white space
- 0.5-1 inch margins
- Line spacing: 1.2-1.5

### Consistency
- Same layout for comparison slides
- Consistent color coding
- Same icons throughout
- Professional medical aesthetic

## 🛠️ PowerPoint Tips & Tricks

### Creating Diagrams

1. **Use SmartArt:**
   - Insert → SmartArt → Process or Hierarchy
   - Customize colors to match palette

2. **Manual Shapes:**
   - Insert → Shapes → Rectangles for body regions
   - Insert → Shapes → Arrows for blood flow
   - Insert → Shapes → Lines for vessels
   - Group related shapes (Ctrl+G)

3. **Adding Effects:**
   - Right-click shape → Format Shape
   - Add subtle shadows (Offset: 2-3pt)
   - Use gradient fills sparingly

### Animations (Optional)
- Use "Appear" or "Fade" animations
- Avoid flashy transitions
- Keep it professional for medical setting
- Sequence: Diagram → Features → Clinical

### Accessibility
- High contrast text (dark on light)
- Large fonts (minimum 18pt for body)
- Color + pattern/text (don't rely on color alone)
- Alt text for all images
