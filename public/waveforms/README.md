## Creating Waveforms

Each waveform should clearly show:
1. **S1 markers** (first heart sound) - typically shown as vertical lines
2. **S2 markers** (second heart sound)
3. **Systole shading** (optional, the S1→S2 window)
4. **Murmur envelope** (the characteristic shape of the murmur)

You can:
- Screenshot from auscultation software (Audacity, etc.)
- Use medical illustration tools
- Commission from medical illustrators
- Use Creative Commons licensed images (with attribution)
